# 新媒体内容运营工作台

面向短视频内容团队的一体化生产工具，覆盖「数据看板 → 脚本生成 → 内容审核」全流程。

**在线演示**：https://zsz-252.github.io/content-workbench/

> 本项目为作品集演示版本。所有账号名称、数据指标、内容示例均为虚构，不涉及任何真实业务数据。

## 核心功能

**多模型 AI 接入**　支持 DeepSeek、通义千问、智谱 GLM、Kimi 等主流大模型自由切换，采用 OpenAI 兼容协议统一适配。用户填入自己的 API Key，密钥仅保存在浏览器本地，不经过任何服务端。

**对话式脚本生成**　打开页面 AI 主动引导，选择脚本类型后按需收集参数，生成结果以对话流形式呈现。支持多轮追问持续调优，例如「第二段太长了，压缩一半」「开头换个更抓人的钩子」。

**文档解析上传**　长文本字段支持拖拽上传，可解析 TXT / Markdown / SRT / VTT / Word / PDF。字幕文件自动清洗时间轴，Word 与 PDF 采用动态加载，不影响首屏体积。

**六维内容审核**　从法务、平台合规、公关舆情、事实数据、传播效果、账号定位六个维度检查内容风险，输出分级问题清单与修改建议。

**数据看板**　矩阵账号传播数据总览，含趋势图、受众画像、作品排行与目标进度追踪。

## 技术栈

Next.js 16（App Router / 静态导出）· TypeScript · Tailwind CSS · Recharts · mammoth（Word 解析）· pdf.js（PDF 解析）

## 本地运行

```bash
npm install
npm run dev
```

访问 `http://localhost:3000`，在对话输入框左侧的模型选择器中配置 API Key 即可使用 AI 功能。

## 设计说明

**AI 调用不做静默降级**　接口失败时明确提示错误原因并提供重试，不会用预置内容伪装成真实结果——尤其在内容审核场景下，一份看起来正常实则虚构的报告比报错危险得多。

**模型差异做兼容层**　不同厂商对参数约束不一致（如部分模型仅接受固定 temperature），配置层支持按模型覆写请求参数，新增模型只需增加一条配置。

**固定视口布局**　对话区采用聊天工具的经典结构：页面整体不滚动，消息区独立滚动，输入框常驻底部，避免内容增长后输入框被推出视野。
